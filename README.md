## Stack

HTML, CSS et JavaScript, sans framework ni étape de build.

```
.
├── index.html    # page unique (FR + EN)
├── style.css     # styles et animations
├── script.js     # langue, menu mobile, filtres, formulaire, retour en haut
├── icons/        # logos des outils (Devicon)
├── eddie1.jpg    # photo
├── og-image.jpg  # aperçu 1200 x 630 lors d'un partage (LinkedIn, WhatsApp...)
├── 404.html      # page d'erreur personnalisée
├── robots.txt    # consignes pour les moteurs de recherche
├── sitemap.xml   # plan du site
├── cv-eddie-zida-fr.pdf   # CV en français
└── cv-eddie-zida-en.pdf   # CV en anglais
```

## Qualité

- Accessibilité : contrastes AA, étiquettes de formulaire, lien d'évitement, focus clavier visible, icônes décoratives masquées aux lecteurs d'écran
- Référencement : balises Open Graph et Twitter, lien canonique, données structurées schema.org (Person)
- Contenu visible même sans JavaScript, animations désactivées si l'utilisateur réduit les mouvements

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou utiliser l'extension **Live Server** de VS Code.

## Déploiement

Hébergé sur **GitHub Pages** : chaque `git push` sur `main` met le site à jour automatiquement.
