## Stack

HTML, CSS et JavaScript, sans framework ni étape de build.

```
.
├── index.html    # page unique (FR + EN)
├── style.css     # styles et animations
├── script.js     # langue, menu mobile, filtres, formulaire, retour en haut
├── icons/        # logos des outils (Devicon)
├── eddie1.jpg    # photo
└── cv.pdf        # CV téléchargeable
```

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou utiliser l'extension **Live Server** de VS Code.
